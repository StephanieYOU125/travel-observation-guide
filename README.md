# 觀察旅伴 Travel Observation Guide

A mobile-first guided observation app for travel, exhibitions, field visits, and reflective learning.

## 核心功能

- 旅行模式：People / Place / Things / Ideas / Me
- 展覽／參訪模式：Problem / User / Tech / Evidence / Limits / Owner / Cost / Pilot / Scale / Transfer
- 四格觀察：我看到的 → 我的解讀 → 我還不確定的 → 下次怎麼驗證
- Local Storage 自動保存
- 記憶庫分類與篩選
- 行程結束後回顧摘要
- JSON 匯出備份
- PWA，可加入 iPhone 主畫面
- Service Worker，支援離線開啟

## 使用方式

1. 先用「引導」頁看 2–3 個問題。
2. 現場只記最關鍵的觀察，不用把所有東西都記下來。
3. 晚上整理成「看到／解讀／不確定／驗證」。
4. 旅程或參訪結束後，在「回顧」頁收斂成真正值得留下來的收穫。

## GitHub Pages

在 repository 的 **Settings → Pages** 中，將 Source 設為 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/(root)**，儲存後即可取得網站網址。

之後可用 iPhone Safari 開啟網站 → 分享 → **加入主畫面**。

> 讓旅行不只留下照片，也留下可複利的觀察。

使用方法

出發前看 2–3 題；現場只記關鍵字；晚上整理 1–3 筆；旅程結束再做一次回顧。不要試圖把所有東西都記下來。

旅行：People 人｜Place 城市｜Things 體驗｜Ideas 想法｜Me 自己
展覽：Problem 問題｜User 使用者｜Tech 技術｜Evidence 證據｜Limits 限制｜Owner 責任｜Cost 成本｜Pilot 實證｜Scale 規模化｜Transfer 轉移
最重要的四格：
我看到的 → 我的解讀 → 我還不確定的 → 下次怎麼驗證

iPhone 當 App 使用

部署到 GitHub Pages 後，用 Safari 開啟網站 → 分享 → 加入主畫面。資料會存在目前瀏覽器的 Local Storage。
